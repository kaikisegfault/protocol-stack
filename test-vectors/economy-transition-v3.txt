# Economy transition v3 normative vectors.
# Byte counts, offsets, and storage bounds are unsigned decimal integers.
# Every hex value is lowercase and unprefixed.
#
# Every value is rederived by `tools/economy-transition-v3-vectors/verify.py`.
# Wherever both sources can reach a value it is derived twice: once from that
# tool's `expected.py`, which imports nothing from `simulation/` and restates
# the accepted version-one field tables and the Founder Constitution's figures
# by hand, and once from a live run of `simulation/economy_transition_v3/`.
#
# Two kinds of independence carry weight here. Structurally, `expected.py`
# builds the version-one transfer as one flat 136-byte field table, exactly as
# `protocol-primitives-v1` writes it, while the model builds it as a shared
# 80-byte header, a kind-specific body, and a shared 16-byte trailer.
# Behaviourally, `expected.py` reimplements the accumulation cap, the winner
# rule, the split, and the mint walk from the specification's prose, so a
# settlement defect that produced a self-consistent record would still have to
# produce the same record twice.
#
# Two sections are checked against third sources: the compatibility section
# against `test-vectors/protocol-primitives-v1.txt`, and the state-root section
# against `test-vectors/economy-transition-v2.txt`. A non-collision claim proves
# nothing unless the construction it compares against is the accepted one.
