# Economy transition v2 normative vectors.
# Byte counts, offsets, and storage bounds are unsigned decimal integers.
# Every hex value is lowercase and unprefixed.
#
# Every value is rederived by `tools/economy-transition-vectors/verify.py`.
# Wherever both sources can reach a value it is derived twice: once from that
# tool's `expected.py`, which imports nothing from `simulation/` and restates
# the accepted version-one field tables and the Founder Constitution's figures
# by hand, and once from a live run of `simulation/economy_transition/`.
#
# The independence that matters most is structural. `expected.py` builds the
# version-one transfer as one flat 136-byte field table, exactly as
# `protocol-primitives-v1` writes it, while the model builds it as a shared
# 80-byte header, a kind-specific body, and a shared 16-byte trailer. The whole
# compatibility argument is that those two constructions coincide, so it is
# derived from two different shapes rather than restated once. `expected.py`
# likewise derives each base-permission leg from the constitution's per-cycle
# display table rather than copying the manifest's atomic figures.
#
# The compatibility section is checked against a third source: the recorded
# bytes of `test-vectors/protocol-primitives-v1.txt`. The claim that a
# version-two kind-1 transaction *is* the accepted version-one transfer is only
# evidence if the accepted file is what it is compared against.

# The envelope. The header is the accepted transfer's first 80 bytes and the

# version-one transaction is the kind-1 instance of this envelope. Every kind is

# nothing a transaction carries scales with the seat population.
