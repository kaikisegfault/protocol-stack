# Economy transition v4 normative vectors.
# Byte counts, offsets, and storage bounds are unsigned decimal integers.
# Every hex value is lowercase and unprefixed.
#
# Every value is rederived by `tools/economy-transition-v4-vectors/verify.py`.
# Wherever both sources can reach a value it is derived twice: once from that
# tool's `expected.py`, which imports nothing from `simulation/` and restates
# the accepted version-one field tables and the Founder Constitution's figures
# by hand, and once from a live run of `simulation/economy_transition_v4/`.
#
# `expected.py` builds the version-one transfer as one flat 136-byte field
# table, exactly as `protocol-primitives-v1` writes it, while the model builds
# it from a shared 80-byte header, a kind-specific body, and a shared 16-byte
# trailer. It also carries a second implementation of the HUB registry, written
# from the specification's prose, so a defect that kept a self-consistent
# registry would still have to keep the same one twice.
#
# Three sections are checked against third sources: the kind-1 identity against
# `test-vectors/protocol-primitives-v1.txt`, each predecessor root construction
# against its own version's accepted vectors, and the settlement against
# `test-vectors/economy-transition-v3.txt` — which version four imports rather
# than reimplements, so the record it writes must be byte-identical.
