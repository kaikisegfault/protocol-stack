# Economy transition v9 normative vectors.
# Amounts are unsigned decimal atomic units at the eight-decimal denomination.
# Uptime figures are unsigned decimal seconds. Timestamps are unsigned decimal
# milliseconds since the Unix epoch, and month indices are calendar-v1's,
# counted from January 1970. Byte strings are lowercase hex.
#
# Every value here is derived twice: once by
# tools/economy-transition-v9-vectors/expected.py, which imports nothing from
# simulation/ and computes the calendar by accumulating month lengths from 1970
# rather than by the closed form the model uses, and once by a live run of
# simulation/economy_transition_v9. A boolean vector may only be true, because
# its name is the claim.
#
# The fixture is simulation/economy_transition_v9/scenario.py, which binds
# simulation/unreferred_pool's rather than inventing a second one: the genesis
# sits six hours off a day boundary so a window straddles a month boundary, and
# the recorded months reach a single winner, a two-way tie over an odd balance,
# a three-way tie, a month every candidate ran zero seconds in, and a halt that
# leaves two months with no window at all.
