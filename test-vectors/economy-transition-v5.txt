# Economy transition v5 normative vectors.
# Byte counts, offsets, and storage bounds are unsigned decimal integers.
# Every hex value is lowercase and unprefixed.
#
# Every value is rederived by `tools/economy-transition-v5-vectors/verify.py`.
# Wherever both sources can reach a value it is derived twice: once from that
# tool's `expected.py`, which imports nothing from `simulation/`, and once from
# a live run of `simulation/economy_transition_v5/`.
#
# Version five is version four with one field's meaning corrected, so neither
# the model nor the derivation restates what did not move. The model imports
# version four's envelope, key space, registry, settlement, and genesis table;
# the derivation loads version four's accepted `expected.py` by path and
# overrides the eight labels, the four version fields, and kind 11's body
# table. A second hand transcription of one accepted contract would put a
# transcription risk into the artifact whose whole job is to be a second
# opinion.
#
# Four sections are checked against third sources: the kind-1 identity against
# `test-vectors/protocol-primitives-v1.txt`, each of the four predecessor root
# constructions against its own version's accepted vectors, the settlement
# against `test-vectors/economy-transition-v3.txt`, and the entire file against
# `test-vectors/economy-transition-v4.txt` — which is what turns "everything
# else carries over unchanged" from a sentence into a check.
