# Minimum-entitlement boundary study

This standard-library-only package implements ADR 0015 and the normative
minimum-entitlement study v1. It rebuilds the eighty one-unit zero-credit
coordinates, compares strictly funded per-participant and per-raw-work reserve
families with the unchanged zero floor, and measures hidden-principal split
gain under all three accepted reward-distribution mechanisms.

Generate the reviewed design or the complete report with:

```sh
python3 simulation/minimum_entitlement/design.py
python3 simulation/minimum_entitlement/study.py
```

The model is research tooling. Its reserves are calculated credit, not native
claims or production reward rules.
